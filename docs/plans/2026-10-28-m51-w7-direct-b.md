## Key Decisions

- **KD-B1 — where and how the copy runs.** The copy is a new last paragraph of Step 2, right after "Wait for the orchestrator to return its summary." (ruling Q1). The model takes the two paths from the returned summary's `Summary file:` and `Summary copy path:` lines. It writes the directory of `summary_copy_path` as a literal: the same path without its last `/` and the file name. So no `$(dirname …)` is needed. Then come two plain Bash calls, each on its own, with single-quoted literals (ruling Q3; w6-preflight Q10). Steps 3–6 keep their numbers. The alternative, moving the parse ahead of the display in Step 3, was rejected by ruling Q1.
- **KD-B2 — a missing summary file.** The `cp` call fails. The skill shows the tool error and one line, `Review summary not copied: <summary_file>`. It removes the diff dir as Step 6 does (so G3 still holds) and stops. A failed orchestrator never reaches the copy; the failure paragraph after it is unchanged (ruling Q2).
- **KD-B3 — the REFERENCE.md path.** The skill adds the literal line `REFERENCE_MD_PATH: <PLUGIN_ROOT>/skills/review-sdlc/REFERENCE.md` to the Step 2 prompt, with `<PLUGIN_ROOT>` substituted as in Step 0 (ruling Q4). The orchestrator reads only that path. If the line is missing, or no file is there, it returns only `Review failed: REFERENCE.md not found at <path, or "no REFERENCE_MD_PATH line">`. The skill's failure paragraph then re-dispatches once and reports. The orchestrator never searches.
  - The alternative, a new `review.js` manifest field, was rejected by ruling Q4.
  - The one re-dispatch on this error stays. It is wasted when the path is wrong, but the failure path is unchanged by ruling (Q2), and the second failure goes to error-report.
  - The line is the same for every dispatch of one install, so the prompt prefix stays stable (prompt-cache guardrail).
- **KD-B4 — setup-dimensions.** The intro (`:17-20`) names the two `<PLUGIN_ROOT>` paths and says "Read them at those paths. Do not search for them with Glob". `:138` uses the `<PLUGIN_ROOT>` EXAMPLES.md path, because that line tells the model to open the file. `:275-276` stay as they are: they are a See Also list of related files, not a lookup.
- **KD-B5 — one error-report form.** Every one of the 9 lines replaces exactly the token ``Glob `**/error-report-sdlc/SKILL.md` `` with ``Read `<PLUGIN_ROOT>/skills/error-report-sdlc/SKILL.md` ``. The rest of each line ("follow with skill=…" / "follow it, and dispatch …") stays. The harden prose `:344` "canonical Glob-then-follow idiom" becomes "canonical read-then-follow idiom". The path matches `recovering-from-failures.md:248`.
- **KD-B6 — Step 6.** Step 6 keeps only the cleanup. Its call is rewritten as one plain, single-quoted literal call, `rm -rf '<diff_dir>'`, in the same form as the copy calls. The behavioural `rm -rf.*review-diff-…` assertions still match.
- **KD-B7 — the policy.** The dimension source changes `:24` and `:38`. The mirror is then regenerated, and its `:16` and `:30` become the same text (ruling w7-plan2 Q1).
  - The new checklist rule: plugin-own files are read at `<PLUGIN_ROOT>/…` in the main context, or from a path passed in to a subagent, and never located by a Glob over `~/.claude` or the cwd.
  - The new severity row is `high`, like the `find ~/.claude/plugins` row.
  - `:25`/`:17` (Glob specificity) and `:37`/`:29` (too-broad pattern) still apply to any Glob that remains, so they stay. The class grep does not match the new texts.
  - Known tension, disclosed in the PR: the kept dimension `:25` / mirror `:17` example `**/review-sdlc/REFERENCE.md` names a plugin-own file whose Glob the new `:24`/`:16` forbids. It is left unchanged because ruling w7-plan2 Q1 opens only `:24` and `:38`; the example is a follow-up candidate for the arbiter.

Then `diff` must print nothing and validate-copilot-mirror must show 0 drift. Applying the change with Edit and proving it by `diff` is safer than retyping the whole file with Write.

Each skill's change is reviewable on its own. version-sdlc (LEGACY) gets its own commit, so its w4-rule9 disclosure stays attached to one commit.
