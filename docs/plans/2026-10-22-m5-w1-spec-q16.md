## Context

**What problem does this change solve?**

- Today the specs say `--auto` needs `--quality`. Nothing enforces that.
  - A standalone `/execute-plan-sdlc --auto` with no tier either asks anyway or lets the model guess.
  - Under `/ship-sdlc --auto`, execute runs in a forked agent that cannot ask. So the tier is picked silently and not recorded.
- The owner chose option (a) on 2026-10-20 (Q16): under `--auto`, a missing `--quality` defaults to `balanced`, and execute decides it, not ship.

**What prompted this change now?**

- W5.2 creates `scripts/skill/execute.js`, the place where the tier gets resolved.
- The repository rule is spec first. This spec commit lands before the code (AGENTS.md "Spec-driven development"; owner Q16 "in ONE consequence commit that goes first").

## Key Decisions

**Problem in one sentence:** the specs require `--quality` under `--auto`, but nothing enforces it, so unattended runs pick an unrecorded tier.

- **Default in execute, below the resumed tier.** The order is `--quality`, then the resumed state's `quality`, then `balanced`. A resume never re-tiers a run. A default in ship was rejected by the owner: a forwarded `--quality balanced` would override a resumed `minimal` tier (arch review §2, option 2).

- **Interactive runs keep their prompt.** The default applies only under `--auto`, so Q15's "ship asks" decision stays as it is.

- **Edit sentences in place; add no ids.** The rules change meaning only inside existing ids. P-5 stays a one-line proof.

- **Non-goals.**
  - No code, SKILL.md, docs page or test changes. W5.2's feat commit carries the code and tests, and W5.5 carries the user docs (owner Q16 "Carrier").
  - No edit to execute R15, ship A1/R7/R20/R71 or the ship Phases "Params" line (arch review §3.1 "no change").
  - No `site/` refresh in this commit. `node site/scripts/copy-docs.mjs` runs twice in the wave: before the ship run, for the plans+site commit (`docs(#9013): plans and site - wave 1 plans (W5.2)`), and again after the ship run, for a direct commit `docs(#9013): site - mirror wave 1 docs (W5.2)`, because the feat commit edits `docs/cost-tiers.md`.

- **Failure audience.** The W5.2 feat plan and every reader of the two specs. A wrong sentence would make `execute.js` implement a different resolution order.
